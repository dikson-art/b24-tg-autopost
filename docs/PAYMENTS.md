# Зависимости сервиса от платежей

_Автопостинг «Вопросы с лекций» (Битрикс24 → Telegram). Обновлено: 2026-10-04._
_Цель документа: знать, что оплачивается, где это контролировать и что сломается при просрочке._

## Схема сервиса

**Битрикс24 (Диск — источник видео)** → **GitHub Actions (исполнитель)** → **Telegram @doctor_lecture (приёмник)**.
Подписи постов ссылаются на **сайт medinfoservice.org** (размещён на «Сайтах Битрикс24»).

## Смежные платные контуры (НЕ входят в автопостинг)

- **Timeweb VPS** `201.34.156.152` — ~1800 ₽/мес (JEV Hub, транскрибатор, PostgreSQL, Caddy). При неоплате встанут транскрибация/JEV; автопостинг не затронут. Панель Timeweb Cloud.
- **LLM-генерация контент-пайплайна** — платная, ограничена ledger'ом и бюджетом workflow (~$3 на прогон).
- **Хостинг источника** medinfoservice.ru (NS `it-s.name`) — используется в контуре транскрибации; не влияет на автопостинг.

## Критические точки контроля (минимум)

1. **GitHub Billing** — способ оплаты действителен; расход Actions в пределах лимита/согласованного бюджета. Автопостинг расходует ~2 мин на прогон, 5 прогонов/день → **до ~300 мин/мес**; общий расход аккаунта смотреть суммарно (контент-пайплайн — отдельно).
2. **Подписка Битрикс24** — срок и автопродление (портал + сайт).
3. **Домен medinfoservice.org (REG.RU)** — включить автопродление и держать карту актуальной.
4. **Timeweb** — продление VPS (смежный контур).
5. **Ежемесячно (1-го числа)** — быстрая проверка живости: `gh run list -R dikson-art/b24-tg-autopost` и `state.json` (сколько постов вышло/осталось).

## Что как ломается (быстрая шпаргалка)

- Нет Битрикс24 → публикации невозможны в принципе.
- Нет GitHub → автопостинг останавливается, но не портится (журнал в репо; продолжит после восстановления).
- Нет домена → посты выходят без рабочих ссылок.
- Нет Telegram-платежей → их и не нужно: бот и канал бесплатны.

## Управление

- Пауза серии: GitHub → Actions → «B24 Telegram autopost» → Disable workflow.
- Резерв на ПК: задача «B24-TG-Autopost» (выключена; включить: `Enable-ScheduledTask -TaskName "B24-TG-Autopost"`).
- В AutoClaw стоит ежемесячное напоминание о платёжном чек-апе (1-е число, 10:00 МСК).
